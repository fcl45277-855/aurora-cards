# Reproducing the paper

Run all commands from the repository root with `AQ_CKPT_DIR` and `AQ_ERA5_DIR` set (see `docs/DATA.md`). Results go to `results/<card>__<split>_h<steps>/` with `records.jsonl` (per date, step and variable), `summary.json` and `build_info.json`. GPU times are for one RTX 5090 (32 GB) with `AQ_PERCEIVER_CHUNK=16384`, which keeps the peak memory near 15 GiB.

**Order matters.** On every split, run the `fp32` card first. It writes the full-precision reference that all other cards are scored against (`results/_ref_fp32_h<steps>/`). Recipes using GPTQ or smoothing also need the 7 calibration days (`calib` split) on disk.

```bash
export AQ_PERCEIVER_CHUNK=16384
python scripts/paper_tables.py --results results     # after a re-run: compare against the paper's values
```

Table, figure and section numbers below refer to manuscript version v17 (C&G) and its supplement (S1–S14).

## Without a GPU: from the result archive

The commands below recompute statistics and redraw figures from saved results without re-running forecasts. Some also need repository files or a checkpoint, as listed. The full result archive `aurora-cards-results-v1.zip` (554 MB) contains per-record results (`records.jsonl` for each card) and `_*.json` aggregates. Its Zenodo DOI has not been assigned yet; until deposition the archive is available from the corresponding authors. Unpack it in the repository root to create `results/`, `results_finetuned/` and `results_small/`, where the scripts below look for inputs by default:

```bash
unzip aurora-cards-results-v1.zip -d .
```

### Earth Science Informatics artwork

`AQ_RESULTS=. python scripts/paper_figures.py --esi` exports Fig2–Fig7 to `figures_esi/` as `.pdf`, `.eps`, `.tiff` (600 dpi) and `.png`, following the revised Earth Science Informatics numbering. Fig. 1 depicts the study design and is not generated from results. Figures are 174 mm wide, with lettering ≥ 8 pt and lines ≥ 0.5 pt. Fig. 3a uses the 25 March rollout dates in Table 9 and adds t7_a16 without the low-rank branch; Fig. 3b adds its storage point; Fig. 4 uses a 2 × 2 map layout. The script adjusts undersized text and lines, refits the layout and stops if the final audit fails. Arial is preferred; Liberation Sans is a metrically equivalent fallback (Debian/Ubuntu: `apt install fonts-liberation`, then delete `~/.cache/matplotlib`). Without `--esi`, Figs. 1–5 remain pixel-identical to version 1.1.0.

## Determinism

Rotation uses `SEED` in `cards/harness.py`; calibration dates are fixed. GPTQ, smoothing and the low-rank branch are deterministic given the calibration statistics. Printed-digit reproducibility depends on the recipe, software environment and RNG state. Different GPUs or library versions can alter the final digits through accumulation order. Bootstrap intervals use seed 0.
